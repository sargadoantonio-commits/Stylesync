Place the Ethnocentric font files here to enable custom app typography.

Required files:
- Ethnocentric-Regular.ttf
- Ethnocentric-Bold.ttf

Recommended additional font files for headings and body text:
- Orbitron-Regular.ttf
- Orbitron-Bold.ttf
- Inter-Regular.ttf
- Inter-Medium.ttf

Once the files are added, run:
  flutter clean
  flutter pub get

Then rebuild the app.
